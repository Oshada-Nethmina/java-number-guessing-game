# Java Number Guessing Game

## 📌 Description
A console-based Java game where users try to guess a randomly generated number.

## ✨ Features
- Random number generation
- Limited attempts
- Input validation
- Too high / too low hints
- Win/Lose conditions

## 🛠 Technologies Used
- Java
- Random Class
- Scanner Class
- Loops & Conditions

## ▶️ How to Run

Compile:

```bash
javac NumberGuessingGame.java
```

Run:

```bash
java NumberGuessingGame
```
